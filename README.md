# 袜子高度控制器 · Sock Height Controller

「它就像美少女下半身的滑动变阻器」

一个纯前端的互动小网页:拖动滑块,实时控制角色袜子的高度 ——

光腿 → 船袜 → 短袜 → 中筒袜 → 及膝袜 → 过膝袜 → 大腿袜 → 连裤袜

## 玩法

- **滑块**:从 0% 到 100% 无级调节袜子高度(支持键盘方向键)
- **绝对领域**:滑到过膝 / 大腿袜区间会触发 ✦绝对领域✦ 徽章,角色还会脸红
- **换色**:黑 / 白 / 藏青 / 粉 / 紫白条纹五种配色
- **连裤袜**:拉满后袜子收进裙底,自动切换为丝袜质感(半透明 + 高光)

## 运行

零依赖,零构建 —— 直接用浏览器打开 `index.html` 即可。

```
open index.html
```

角色与所有装饰均为内联 SVG 手绘,无任何外部资源。
